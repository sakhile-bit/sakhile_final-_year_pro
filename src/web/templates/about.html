About the Program

Zambia Digital Hygiene Certification Program — Final Year Project, University of Zambia

What is this?

The Zambia Digital Hygiene Certification Program provides SMEs in Zambia with a practical, affordable, and recognised pathway to baseline cybersecurity compliance. The Windows desktop application assesses 15 essential security controls and awards Bronze, Silver, or Gold certification.
